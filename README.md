# Client Marketing Strategy and Roadmap — US

A complete marketing system for consultants who build client-facing strategy sites and lead-generation pages.

This repository contains two working examples built for a real client:

- **Regina Brooks Course Strategic Plan Site** — A full playbook website covering strategy, marketing, AI support, and launch planning.
- **Regina Memoir Course Landing Page** — A high-conversion founding-cohort landing page with application flow.

Both projects are deployed and ready for review.
